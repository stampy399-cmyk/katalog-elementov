# Переподбор референсов для D-семейств

Дата: 2026-08-13.

Проверены напрямую исходные MP4: 7/7 (`SRC-TRE`, `SRC-NNG`, `SRC-GMK`, `SRC-4QR`, `SRC-ZCH`, `SRC-QOU`, `SRC-4WP`). Описания разметки использовались только для навигации; каждый принятый и переназначаемый фрагмент проверен по кадрам исходного видео. Ничего не нарезано и не изменено.

## 1. KEYFRAMES-MOTION

Наш образец: `assets/ours/keyframes-motion.mp4` — кит въезжает справа, затем вокруг головы рисуется бирюзовый контур и посимвольно появляется подпись; в конце композиция уходит влево.

Новые референсы:

1. **Основной — `SRC-TRE`, 03:24.550–03:27.783.** Вырезанная фигура святого появляется слева, справа по фазам собираются заголовок и подзаголовок, затем рисуется белая дуга; совпадают многофазный reveal, схема «объект слева + подпись справа» и рисуемая линия.
2. **`SRC-4QR`, 05:08.717–05:10.700.** На гравюре появляется плашка `GASBATTERIE`, после неё к объекту растёт белая изогнутая линия; совпадает последовательная сборка «объект → подпись → линия».
3. **`SRC-ZCH`, 06:14.300–06:16.200.** На машинном плане сначала появляется плашка `KOMPRESSOREN`, затем к агрегату дорисовывается белая дуга; совпадают объектная выноска, порядок фаз и композиция с линией к предмету.

## 5. OTHER

Наш образец: `assets/ours/other.mp4` — короткая RGB-glitch-смена спикера на карту с хроматическим раздвоением в точке перехода.

Новые референсы не подбирались: по условию текущие три ссылки предлагается перенести в уже существующие семейства, без создания новой структуры.

1. **`SRC-NNG`, 00:47–00:51 → `TEXT-TYPOGRAPHY`.** В центре меняется год на горизонтальной временной шкале; главный управляемый элемент — анимированная числовая типографика.
2. **`SRC-GMK`, 03:59.500–04:10.500 → `KEYFRAMES-MOTION`.** Локальный YouTube CTA проходит несколько UI-состояний (`like`, `subscribe`, `subscribed`, `bell`); это многофазная keyframe-микроанимация оверлея.
3. **`SRC-4QR`, 01:45.000–01:47.800 → `TEXT-TYPOGRAPHY`.** Слово `VERLUSTE` набирается посимвольно поверх красной заливки; основной приём — кинетическая типографика.

Предложение владельцу: перенести карточки в указанные существующие семейства; `OTHER` не использовать как визуально однородную пару.

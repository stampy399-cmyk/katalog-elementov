## Изменения

- Изменён `index.html`; `data.json` не менялся.
- Сверху вкладки добавлены крупная кнопка `ПРИЁМКА` и `ЭКСПОРТ РЕШЕНИЙ`.
- Полноэкранный режим показывает одну карточку: крупный кадр/клип, приём, машинное семейство, текущий русский раздел, tier, ручной чип, ролик и таймкод.
- Детерминированная очередь: сначала 63 карточки серой зоны, затем 693 карточки по жёсткому порядку русских разделов. Прогресс считается отдельно для этапов: `N из 63`, затем `N из 693`.
- Реализованы ответы `БАЗА`, `УНИК`, `МУСОР`, `РАЗДЕЛ НЕ ТОТ`, `ЭТО СКЛЕЙКА`, `ОК, ДАЛЬШЕ`.
- `РАЗДЕЛ НЕ ТОТ` содержит 6 простых разделов и спойлер со всеми 18 машинными семействами.
- `ЭТО СКЛЕЙКА` содержит однострочный текстовый ввод и нативный голосовой ввод Web Speech API, если он доступен браузеру.
- Решение хранится в существующей записи карточки в IndexedDB store `elements`, поле `acceptance`: `{id, verdict, family?, combo?, ts}`. Новый store/вторая база не создавались.
- Сохранение выполняется существующим `saveElement(..., false)`/`commit`, поэтому работает индикатор `Сохранено`, общий экспорт JSON, автобэкап и merge «Обновить с сервера».
- `МУСОР` только ставит `verdict: "trash"`; карточка не удаляется.
- Отдельный экспорт скачивает `resheniya-priyomki.json` — массив только валидных решений.
- Повторный запуск продолжает с первой карточки без валидного решения.

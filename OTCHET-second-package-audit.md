## 2. Нумерация по хронологии (`#01` = первый добавленный)

### Что работает

- В рамках одной непрерывной сессии новые элементы добавляются в конец `state.elements` (`:1771`, копирование — `:1837-1843`), поэтому `elementNumber()` обычно выдаёт порядковый номер добавления.
- Формат с ведущим нулём и якорь реализованы в `:1333-1335`, карточка выводит `#NN` в `:1457-1460`.
- Поиск по `#N` и `#NN` подключён в `:1364-1384`.

### Дефект

`elementNumber()` не использует `createdAt`:

- `/Users/alphabravo/Downloads/katalog-site/index.html:1328-1331` — номер равен позиции в `elementsForProject()`.
- `elementsForProject()` сохраняет порядок `state.elements` без сортировки (`:1266-1268`).
- При загрузке IndexedDB используется `getAll()` (`:1081-1087`), а результат напрямую кладётся в `state.elements` (`:1105-1111`). Ключ элемента — случайный UUID (`:693-697`), поэтому порядок ключей не равен хронологии добавления.
- Cloud apply также собирает элементы через `Map`/массив без сортировки (`:2975-3004`), а merge сохраняет порядок `localRows → remoteRows → baseRows` (`:2747-2759`). Импорт принимает порядок файла (`:3333-3356`).
- Тот же позиционный порядок используется в экспортных `localNumber`/`globalNumber` (`:3424-3432`) и имени anchor (`:1333-1335`).

Итог: требование выполняется только пока массив случайно совпадает с порядком создания. После refresh первый созданный элемент может получить не `#01`.

## 3. Presence-счётчик

### Что работает

- `repeatCount` нормализуется минимум в 1 (`:940-945`).
- Карточка показывает `×${element.repeatCount}` (`:1462`); обычный клик увеличивает, Alt-клик уменьшает, но не ниже 1 (`:1818-1834`, делегирование — `:3741-3742`).
- Шапка ролика пересчитывает количество элементов и повторов (`:1410-1419`, точечное обновление — `:1633-1639`).
- Для категорий внутренний `uses` действительно считает число элементов, а `repeats` — сумму повторов (`:835-847`); значения нормализуются при upgrade (`:986-1003`) и пишутся в IndexedDB (`:868-871`).

### Что недоделано/неоднозначно

- Отдельного видимого presence-счётчика категории нет: `uses` нигде не отображается в picker, sidebar или stats. Поэтому наличие данных в IndexedDB нельзя считать готовым пользовательским feature.
- `×N` — счётчик повторов конкретной карточки, не счётчик фактического присутствия категории/элемента во всех роликах. Sidebar показывает только `elements.length` (`:1394-1404`), а не `totalRepeats()`.
- Категорийная статистика выводит количество элементов `item.count` и процент (`:2233-2241`, `:2283-2289`), но не поле `category.repeats`/`category.uses`.

### Дефект

- `focusout` лишь закрывает меню (`:3805-3811`); вызова `selectCategory()` или `updateElement()` там нет.
- Поэтому сценарий «ввести текст → Tab/кликнуть вне поля» оставляет значение только в DOM до следующего render и затем возвращает старую категорию. Для сохранения требуется явно выбрать вариант или нажать Enter.

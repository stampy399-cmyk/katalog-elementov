# ТЗ: Атомы типографики ТИПОГРАФИКА

Анализ: 7 роликов, 224 кадра, извлечённые командой `ffmpeg -vf fps=10`; кадры просмотрены последовательно.

## Заголовок / тезис (zagolovok-tezis)
| Параметр | Значение |
|----------|----------|
| Содержание | Основной титр: `STROM AUS STILLE CHEMIE`. В нижней части — меняющийся субтитр: «Und eine Technologie, die niemand besitzen, messen oder kontrollieren kann, ist eine Technologie, für die keine…». |
| Позиция | Основной титр по центру нижней трети, примерно y=930–975. Фото в белой рамке занимает центр кадра выше титра. |
| Шрифт | Узкий жирный гротеск, капс; субтитр — обычный гротеск. |
| Цвет текста | Основной титр `#FFFFFF` / `#FCFCFC`; субтитр `#FFFFFF`. |
| Цвет фона | `#000000`, с серой сеткой примерно `#4B4B4B`; в центре — видеокадр в белой рамке. |
| Анимация входа | Глитч/сканлайновая переборка и поэтапное проявление: кадры 10–15, 6 кадров, около 0,6 с; к кадру 15 титр полный. |
| Анимация выхода | Жёсткий глитч-срез в чёрную сетку: кадр 56, 1 кадр, около 0,1 с. |
| Подложка | Плашки под основным титром нет; используется белая рамка фото. Нижний субтитр лежит на тёмной полупрозрачной области. |

## Число / метрика (chislo-metrika)
| Параметр | Значение |
|----------|----------|
| Содержание | Нижний субтитр с метрикой: `Ein Autokühler kostet zehn euro.`; в соседних кадрах — фрагмент `mehr rechnet.`. Отдельного крупного числового оверлея нет. |
| Позиция | Нижний центр, примерно x=240–1680, y=970–1058. |
| Шрифт | Обычный санс-гретеск, смешанный регистр, без жирного начертания. |
| Цвет текста | `#FCFCFC`. |
| Цвет фона | Белый видеофон, доминирующий цвет `#FCFCFC`. |
| Анимация входа | Уже присутствует в первом кадре; отдельного входа не обнаружено, 0 кадров. Текст меняется монтажно между субтитрами. |
| Анимация выхода | В пределах ролика не обнаружена; субтитр присутствует в кадре 30. |
| Подложка | Серо-графитовая полупрозрачная нижняя плашка, наблюдаемый цвет около `#7D7D7D`. |

## Текстовая плашка / выноска (tekstovaya-plashka-vynoska)
| Параметр | Значение |
|----------|----------|
| Содержание | Выноска: `SAISONALE MEHRKOSTEN: €200–€400`. Затем вертикальный график с последовательными значениями: `$0.63K`, `$0.71K`, `$0.56K`, `$0.46K`, `$0.39K`, `$0.35K`. Нижний субтитр: «Pro Sommer kommen zweihundert bis vierhundert Euro». |
| Позиция | Выноска по центру нижней половины, примерно x=575–1345, y=756–865. График — по центру, выше нижней плашки. |
| Шрифт | Узкий жирный гротеск, капс; значения графика — белый жирный гротеск. |
| Цвет текста | Текст выноски `#111111`; значения графика `#FFFFFF`; субтитр `#FFFFFF`. |
| Цвет фона | Видеофон; белая выноска `#FDFDFD`. График — полупрозрачные красный `#E65C4C`, оранжевый `#C97A2B`, жёлто-оливковый `#B3A32E`, зелёный `#75C930`. |
| Анимация входа | Горизонтальная белая линия превращается в скруглённую плашку, затем проявляется текст: кадры 10–16, 7 кадров, около 0,7 с. |
| Анимация выхода | На переходе кадр 24→25 выноска заменяется графиком за 1 кадр, около 0,1 с. График держится до кадра 30; отдельного выхода нет. |
| Подложка | Скруглённая белая плашка без заметной тени и обводки; график — полупрозрачная цветная вертикальная плашка. |

## CTA / призыв (cta-prizyv)
| Параметр | Значение |
|----------|----------|
| Содержание | Крупный призыв-акцент `2%`. Нижний субтитр: «Das Rohr muss mit einem Gefälle von mindestens zwei Prozent». |
| Позиция | Крупный текст по центру кадра, примерно x=810–1110, y=340–580; субтитр внизу. |
| Шрифт | Очень жирный широкий гротеск, капс/цифровой знак; субтитр — обычный гротеск. |
| Цвет текста | `#FFFFFF`. |
| Цвет фона | Видеофон; единый hex не применим. Нижняя субтитровая плашка около `#111419`. |
| Анимация входа | Появление с наращиванием opacity: кадры 32–34, 3 кадра, около 0,3 с; кадр 32 полупрозрачный, кадр 34 полный. |
| Анимация выхода | В пределах ролика не обнаружена; `2%` полностью виден в кадре 40. |
| Подложка | У `2%` отдельной плашки, обводки и выраженной тени нет; субтитр — на тёмной полупрозрачной нижней полосе. |

## Логотип / именная подпись (logotip-imennaya-podpis)
| Параметр | Значение |
|----------|----------|
| Содержание | Логотип-эмблема сверху по центру. Сопутствующий заголовок: «DIESES 50€-BETONROHR KÜHLT IHR HAUS FÜR IMMER, WARUM WURDE ES VERDRÄNGT?», жёлтая акцентная строка `EINFACHE TECHNIK, GROßE WIRKUNG`. Нижний субтитр: «Das Passivhaus Institut in Darmstadt empfiehlt». |
| Позиция | Логотип примерно x=875–1045, y=155–250; заголовок — верхняя/средняя центральная зона; субтитр внизу. |
| Шрифт | Заголовок — узкий жирный гротеск, капс; акцент — тот же; субтитр — обычный гротеск. |
| Цвет текста | Основной заголовок `#FFFFFF` / `#D0D0D0`; акценты и часть логотипа `#F0D000`; красный элемент логотипа около `#9B2025`. |
| Цвет фона | Дымчатый тёмно-серый фон `#333333–#505050`, серая сетка около `#666666`. |
| Анимация входа | Логотип и подпись проявляются с глитч/opacity-переходом: кадры 10–14, 5 кадров, около 0,5 с; к кадру 20 композиция полная. |
| Анимация выхода | В пределах ролика не обнаружена; логотип и подпись держатся до кадра 20. |
| Подложка | Логотип размещён на чёрной прямоугольной панели `#000000`; нижний субтитр — на тёмной полупрозрачной полосе. |

## Список / пункты (spisok-punkty)
| Параметр | Значение |
|----------|----------|
| Содержание | Видимый текстовый маркер справа: `KOS`. Отдельных буллетов и списка в ролике не обнаружено. Нижний субтитр: «Und dagegen steht ein Autokühler für zehn Euro, ein». |
| Позиция | `KOS` — вертикальная правая зона, примерно x=1750–1920, y=313–377; субтитр — внизу. |
| Шрифт | Узкий жирный гротеск, капс; субтитр — обычный гротеск. |
| Цвет текста | `#FFFFFF`. |
| Цвет фона | Видеофон; правая полоса `#090909`. |
| Анимация входа | Маркер `KOS` присутствует уже в кадре 1; отдельного входа не обнаружено, 0 кадров. |
| Анимация выхода | В пределах ролика не обнаружена; маркер присутствует в кадре 30. |
| Подложка | Сплошная чёрная вертикальная полоса справа; субтитр — на тёмной полупрозрачной нижней плашке. |

## Текстовая плашка (tekstovaya-plashka)
| Параметр | Значение |
|----------|----------|
| Содержание | Основной текстовый акцент: `KEIN WARTEN`, появляющийся через промежуточное `KEIN`. Нижний субтитр меняется на «Kein Warten auf Sonnenstunden.». |
| Позиция | Основной текст — сверху слева после монтажного среза, примерно x=190, y=225; субтитр — внизу. |
| Шрифт | Узкий жирный гротеск, капс, Impact-подобное начертание; субтитр — обычный гротеск. |
| Цвет текста | `#FFFFFF`. |
| Цвет фона | До среза — видеосцена; после среза тёмное небо около `#18141C`. |
| Анимация входа | Жёсткий монтажный срез на кадре 34, затем последовательное печатание/проявление: кадр 35 — `KEIN`, кадр 38 — `KEIN WARTEN`; 4 кадра, около 0,4 с. |
| Анимация выхода | В пределах ролика не обнаружена; полный текст держится в кадре 38. |
| Подложка | У `KEIN WARTEN` отдельной плашки, тени и обводки нет; нижний субтитр — на тёмной полупрозрачной полосе. |

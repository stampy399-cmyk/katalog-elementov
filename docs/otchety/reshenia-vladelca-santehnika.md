# Решения владельца по раскладке кирпичиков (ниша сантехника)

Формат: название кирпичика (повторов) — семейство, база/уник. Источник: Александр, диктовка в чат 14.08.2026.

1. Падающие листья поверх кадра (128 повторов, предст. P3 14:36.550) — Частицы, база. Комментарий владельца: листья на фоне хромакея поверх футажа. Примечание: в данных группа называлась «Текстовая плашка» — название группы спорное, внутри могли склеиться текст-подпись и листья, проверить при чистке.
2. Заголовок / тезис (50 повторов, предст. P3 15:09) — Типографика, база.
3. Число / метрика (28 повторов, предст. P1 6:50) — Типографика, база. Скрин на карточке неверный (радиатор вместо титра €800), владелец проверил момент на YouTube — крупные цифры с поясняющим титром.
4. Текстовая плашка / выноска (11 повторов, предст. P2 1:32) — Типографика, база.
5. CTA / призыв (9 повторов, предст. P2 12:03) — Типографика, база. Представитель по факту «число 2% + подпись уклона», скрин карточки тоже кривой (экскаватор).

## Ручной разбор владельца: ролик «Dieses 50€ Betonrohr…» (QOUszAHEZAE, 613К просмотров)

6. ~0:00–0:01 Переход-наложение (cross dissolve, два кадра просвечивают) + зум в центр + глитч-эффект + SFX-вжух — БАЗА, частая комбинация. Приём из 4 атомов: склейка-наложение, зум, глитч, звук. Семейство приёма: Переходы.
7. Искажение фото (warp/distortion кадра) — УНИК, редко используют. Семейство: Камера/футаж.
8. ~0:05 Инфографика-список: жёлтый значок «внимание» + пункты с буллетами (KEIN KOMPRESSOR / KEIN KÄLTEMITT. / KEIN STROM), от ролика к ролику меняются только количество пунктов и текст — Инфографика, шаблон с параметрами (текст, число пунктов).
